# Outputs Directory

This directory contains evaluation artifacts and visualizations generated by the pipeline.
All files here are safe to commit — they contain **no student PII**, only aggregate metrics.

## Metric Files (Reproducible from Code)

| File | Description |
|------|-------------|
| `ranking_metrics.json` | Baseline XGBRanker: NDCG@k, MAP@k, Hit@k |
| `ranking_metrics_tuned.json` | Tuned XGBRanker after 50-trial Optuna optimization |
| `ranking_optimization_results.json` | Best hyperparameters from Optuna search |
| `ranking_data_summary.json` | Dataset split shapes and feature count |
| `clustering_optimal_k.json` | Optimal cluster count and selection scores |
| `clustering_validation.json` | KMeans / GMM / DBSCAN comparison metrics |
